# Tech Mais - Plataforma de Conteúdo Tech

Sistema completo de gerenciamento de conteúdo com painel administrativo, banner personalizável e timeline de posts.

## Funcionalidades

- ✅ Banner fixo com efeito parallax
- ✅ Timeline de posts com suporte para:
  - Texto
  - Imagens
  - Vídeos (local e YouTube)
- ✅ Painel administrativo completo
- ✅ Compartilhamento em redes sociais
- ✅ Design 100% responsivo
- ✅ Sistema de login seguro

## Tecnologias

- Python Flask
- SQLite
- Bootstrap 5
- HTML5/CSS3
- JavaScript

## Instalação Local

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/tech-mais.git

# Entre na pasta
cd tech-mais

# Crie ambiente virtual
python -m venv venv

# Ative o ambiente
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Instale dependências
pip install -r requirements.txt

# Execute
python app.py
